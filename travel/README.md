# Travel · 全球旅游计划

网站页脚默认折叠的 Travel → 全球旅游计划。页面无主导航项，`sitemap: false`，并带 `noindex,nofollow,noarchive`。仍是公开页面，不提供访问鉴权。

## 文件与维护

- `index.html`：独立页面、样式、交互和 `script#travel-data` 内的中英行程数据；网页、打印与双语 Markdown 下载共用数据。
- `images/`：仅保存经过视觉检查、清除 EXIF/XMP 等元数据的风景照片网页副本。原始图库、原片、抽取文本、视频与文件标识不进入仓库。
- `README.md`：维护说明，已从 Jekyll 输出排除。

行程 `kind` 为 `visited` 或 `planned`。默认分类为“全部”，包括 5 个已去过目的地和 2 个未来计划；hash 深链接定位行程。中英文均采用“旅游目的、行程安排、攻略参考、出行提示”。可选 `photos` 字段包含相对路径、双语图注、宽和高。无照片的行程不显示空白占位。

对外页面只呈现旅行内容。材料缺漏、视频集数、核对过程与待确认事项留在维护流程中，通过对话补全后再更新，不将分析说明写入网页或下载。不得将未确认的计划写成已完成活动。
